prsnoop simonw --days 30

one username in. a report out.

It fetches pull requests, reviews and issues for one GitHub user over a time window, computes the metrics that matter, then renders them. Built for a developer writing a review line, a maintainer triaging a backlog, a team comparing contributors, and a CI pipeline.

prsnoop auth && grep -n retry prsnoop/github.py

built to fail politely.

tokens

Reads PRSNOOP_TOKEN or GITHUB_TOKEN from the environment only. Never written to disk, never logged.

rate limits

429s and server errors retry with backoff. Hard exhaustion fails fast with exit 4 instead of hanging.

caching

ETag revalidation on every request. A 304 costs no quota, so re-runs are free.

exit codes

0 ok, 2 usage, 3 API error, 4 rate limit. Scripts branch on the code, not on text.

no partial lies

Past 300 PRs, line totals are marked partial rather than reported wrong.

timeout safety

Every request has a timeout, so one slow endpoint cannot wedge a report.

deterministic output

Renderers are pure functions over a snapshot: same input, byte-identical output. That is what makes the 260 tests meaningful.

Live check: core 4889/5000 remaining, search 30/30 remaining. That is why a warmed run answers in about a second.

wrapped and the web surfaces

wrapped is the Spotify-style year in review, as table, markdown, json, or a swipeable web story.

showcase writes a single-file web app, battle a head-to-head versus page, report a one-page HTML document, card a 640x340 SVG. Every page is one file, no external requests.

it reads the room

forecast fits a least-squares line and projects pace, here about 5 PRs.

and the event layer

timeline turns a window into an event stream; network graphs work and review flow as Graphviz DOT; digest formats it for Slack, email or Discord.

export writes the report pack, snap freezes a window to JSON, replay re-renders offline.

the test suite

260 tests across 13 files, all offline: HTTP is faked, so the suite proves rendering and statistics without touching the network. It grew from 47 tests at v1.0.

Deterministic renderers plus offline tests mean a change either reproduces exactly or fails loudly. That is how 30 subcommands landed without breaking an earlier format.

the CI matrix

One workflow fans out over 15 runners: Ubuntu, macOS and Windows against Python 3.10 to 3.14, each running pytest, ruff and mypy strict. Three more ship: Pages deploy, release build, weekly report.

packaged to be used

Pure Python with no dependencies, so it installs anywhere. A reusable GitHub Action files a report as an artifact with no local setup. Ten tagged releases ship with built distributions.
