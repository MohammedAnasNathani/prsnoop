github.py talks to the API. fetch.py gathers activity. stats.py does the math. models.py holds the data. render.py prints reports. badge.py draws badges.

No outside packages, so it installs anywhere. Tests run on saved responses. Reports come out identical, and repeats reuse the cache.
Extras: serve.py, a local server; wrapped.py, a year-in-review; org.py, org pulse.
