02 · initial research

We went looking for the tool.
It did not exist.

F-1

The CLI gap is empty

No maintained command-line tool generates personal PR analytics. The closest hobby repos sit near ~13 stars: unmaintained, undocumented.

F-2

Dashboards are crowded

OpenSauced and OSS Insight are funded web apps: signups, onboarding, hosting. Nothing that runs over SSH, in CI, or in a cron job.

F-3

gh CLI stops halfway

GitHub's official CLI (46k stars) can list PRs, but every report means hand-writing jq + GraphQL pipelines from scratch.

05 · technical approach

Stdlib only. The whole import tree is already installed.

github.pyurllib client · token auth · ETag cache
fetch.pysearch API · per-PR enrichment · 300-PR budget
stats.pyrates · median + p90 · streaks · heatmap
models.pydataclasses · no loose dicts
render.py5 formats · pure functions · ASCII-safe
badge.pyhand-built SVG · no service
0 runtime dependenciesno network in testsdeterministic renderersETag revalidation: 304 = free

08 · literature review

What exists, and where each one stops.

ToolApproachLimitation (the gap)
gh CLI (GitHub, 46k ★)Official CLI: list PRs/issues, script with jq/GraphQLNo analytics; every report is a hand-built pipeline
OpenSauced (funded OSS)Web dashboards, workspaces, browser extensionsSignup + hosting; cannot run in terminal, CI, or cron
OSS Insight (PingCAP)Ecosystem-scale event analytics over billions of rowsRepository research, not personal contribution reports
prsnoop (this work)Zero-dep CLI: one command → five report formatsNew; ecosystem integrations (PyPI, editor plugins) are roadmap
